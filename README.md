# 问数 AskDB

## 一切都尚未实现

> 接上你的数据库，向AI提问，自动查询你的数据库。  
> 智能数据库查询，无需写 SQL。

[![Python](https://img.shields.io/badge/python-3.13-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()

## 功能

- 中文自然语言提问，自动查询MySQL。
- 支持多数据库源配置与一键切换
- 自动读取数据库结构，支持人工补充业务口径。
- 账号密码登录，管理员/普通用户
- 只读安全闸：单句SELECT，表名白名单，自动LIMIT
- Docker一键部署
